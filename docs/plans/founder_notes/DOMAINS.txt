 To stop this happening: run the frontend container as a production build (next build once, then next start). Pages are compiled ahead of time, so there's no first-visit compile and no half-written files, and pages load in milliseconds. The cost is no live reload when code changes, so you rebuild the container after edits. Three ways to do it:
- a) Add a production setup next to the dev one, e.g. docker compose -f docker-compose.yml -f docker-compose.prod.yml up. (Recommended)
- b) Switch the container to production entirely.
- c) Leave dev mode as it is, and hard-refresh after the first compile
