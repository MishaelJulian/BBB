# Inspiration atlas (BBB UI revamp)

Researched 2026-10-13. Labels: **fact** = from a cited source, **inference** = my reading, **rec** = recommendation. Format follows the founder's UIUX notes: Site | Borrow | Don't borrow | Implementation (not "looks nice"). See `ADR-ui-revamp.md`.

| Site | Borrow | Don't borrow | Implementation in BBB |
|---|---|---|---|
| **Linear** ([design refresh](https://linear.app/blog/behind-the-latest-design-refresh)) | Fact: principle "don't compete for attention you haven't earned"; dimmed navigation so main content leads; compact tab bars; fewer icons; softened borders and separators. Rec: apply it as the BBB rule for chrome vs content. | Dense issue-tracker toolbars; keyboard-first complexity. | Header and footer in a low-contrast ink tone; book/meetup content gets the highest contrast; borders as hairlines (`border-border` at low alpha), icons only where a label is not enough. |
| **Fey** ([overview](https://artisan-apps.beehiiv.com/p/fey-where-bloomberg-meets-apple-s-design)) | Fact: starts with essentials and introduces more metrics as the user grows comfortable; a curated feed from a personal watchlist; AI-style summaries. Founder file (`site insposlist.txt`): calm greeting, one real status line, two quiet text links. Rec: same tone for `/account` ("Hello, name" + "3 books of yours in the archive"), computed from real data only. | Finance jargon, ticker animations, anything implying live data we do not have. | `/account` header and meetup page lead: one sentence of real status, two text links. No invented numbers (memory rule: counts from the live DB). |
| **Mercury** ([breakdown](https://www.925studios.co/blog/mercury-design-breakdown)) | Fact: calm colour system with colour reserved for state and errors; one accent applied with restraint to primary actions and interactive states; product language, not insider language. | Six-button action row (founder notes already reject it); account switchers. | One accent (BBB brown) for actions and current state only; status as coloured text; labels in plain reader words ("Discussed at meetup 99", not DB terms). |
| **Criterion Collection closet** ([article](https://80.lv/articles/this-virtual-closet-lets-you-browse-1-000-criterion-collection-films)) | Fact: ~1,000 editions arranged in spine-number order like a collector's shelf, with both a list view and a closet view and mobile support. This is the closet idea BBB's Library Room is built on. | The room's per-spine 3D cost at 360 spines per section (see audit). | Keep spine order and the list view; flatten the spines (Phase C) and keep the 3D room as backdrop only. |
| **StoryGraph vs Goodreads** ([critique](https://ixd.prattsi.org/2024/09/design-critique-storygraph-beats-goodreads-but-could-be-better/)) | Fact: a minimal look that centres "books and you"; stats placed prominently; lists easier to sort and navigate. Fact (critique): the full "read" list takes several menu steps and is hard to find. | Burying the main list behind menus. | Member page shows their books first; one-click path from any member or book to its full list; no stats we cannot compute. |
| **Progressive disclosure** ([overview](https://en.wikipedia.org/wiki/Progressive_disclosure)) | Fact: defer advanced or rarely used features to a secondary screen; reveal when relevant. This is the pattern behind PRD Flow D. | Hiding the one primary action. | Thin shelf first, detail on hover/pointerdown/open; filters grouped (<=7). |
| **Mobbin, refero.design, 21st.dev, saas-ui.dev, twenty.com** | Founder list (`UIUX_Refer_Please-MANUAL.txt`): Mobbin for screens and flows, refero for text-heavy sections, 21st.dev for components, twenty.com as a code base to learn from. | Copying whole layouts or paid components. | **Not researched this round**: these need a browser session or login; use during mockup work (Phase 0b), cite pages actually viewed. |
| **brandur.org, tomtunguz.com, pragmaticengineer, stripe.dev** | Founder's pasted blog list. Inference: long-form text sites; rec: use their reading measure and calm rhythm for the Terms/Privacy/FAQ pages. | Their content structure (blogs, not archives). | **Not verified**: a search for brandur.org returned no design information about it. Open the sites and check measure, size, line-height before copying numbers. One general source in the results suggests prose width of about 36-42rem and line-height 1.62-1.68, but that source is unnamed and unverified. |
| **Fingerprint.com (refero)** | Founder note: its text-heavy sections as a model for "mini report" blocks. | n/a | **Not verified**: the search returned nothing about it. Needs a refero visit. |

## Filmmaker lenses (review only, never implementation personas)
From the founder's note: Deakins = composition and eye guidance; Villeneuve = materiality and restraint; Anderson = alignment, rhythm and balance. Use them as a final review checklist on each page.

## Gaps
Mobbin/refero/21st.dev/twenty.com, brandur, Fingerprint and bklit.com were not opened. The atlas is incomplete until those are viewed in a browser.
